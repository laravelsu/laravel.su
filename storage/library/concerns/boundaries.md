---
title: "Где проходит граница"
description: "Выбираем между методом модели, Concern, базовым классом и Action."
---

Само наличие трейта ещё не делает решение удачным. Важно выбрать место, которое соответствует масштабу правила.

- **Метод модели** подходит, если правило относится только к одной модели. Не стоит создавать `Archivable` заранее,
  пока архив существует лишь у `Post` и нет подтверждённого повторения.
- **Concern** нужен, когда несколько моделей разделяют один смысл и одну реализацию. Для `Post`, `Comment` и `Page`
  архив должен означать одно и то же.
- **Базовая модель** уместна для правил, обязательных для всех моделей приложения. Архивация обычно подключается выборочно,
  поэтому наследование здесь создаст лишнюю связь.
- **[Action](/library/actions)** лучше подходит для операции, которая проверяет права, изменяет несколько объектов,
  отправляет уведомления или обращается к внешней системе. Эти действия не относятся к состоянию одной модели.
- **Наблюдатель** нужен, когда код должен реагировать на событие жизненного цикла Eloquent независимо от места вызова
  `save()`. Он не заменяет команду `archive()`, которая выражает намерение пользователя.

Например, переход записи в архив остаётся в модели, а проверку прав и отправку уведомлений можно вынести в Action:

```php
final class ArchivePost
{
    public function __invoke(User $actor, Post $post): void
    {
        Gate::forUser($actor)->authorize('archive', $post);

        $post->archive();
        $post->subscribers->each->notify(new PostArchived($post));
    }
}
```

Здесь `ArchivePost` проверяет права и отправляет уведомления, но не присваивает `archived_at` самостоятельно. Правило
состояния по-прежнему принадлежит `Archivable`, поэтому его невозможно случайно реализовать иначе в другом месте.

Архив также не следует подменять `SoftDeletes`. Мягкое удаление исключает запись из обычных запросов и описывает её
удаление. Архивную запись часто продолжают показывать, искать и возвращать в работу. Сходство `archived_at` и
`deleted_at` не делает эти состояния равнозначными.
